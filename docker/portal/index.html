💡 使用说明

# 启动 / 更新（首次会自动构建镜像，约 1 分钟）
docker compose up -d --build

# 改了 .env：重建容器才会读入新值（restart 不会）
docker compose up -d

# 查看状态 / 日志 / 停止
docker compose ps
docker compose logs -f listening
docker compose down
  • 密钥：在仓库根目录 .env 里填一次 DEEPSEEK_API_KEY，7 个应用共用；也可以各应用目录自己的 .env 里分别填（根目录 .env 优先级更高）。
  • 改提示词：prompts/*.txt 改完即生效（应用每次请求都重读，无需重启）。
  • 全局默认引擎：上面那一栏直接切（写进 settings.json，7 个应用共用）；单次做题还能在各应用的设置区临时切。
  • 引擎与密钥：打开上面「⚙️ 引擎与密钥配置」→ 可视化改接口地址、认证方式、JSON 模式、填两家密钥、一键测试连通性。保存即生效（无需重启），密钥只写不回显。
  • 改 .env：执行 docker compose up -d 按新配置重建容器 —— 注意 docker compose restart 只重启进程、不会读入根目录 .env 的新值；改 app.py 用 docker compose restart 即可。
  • 改端口：只改根目录 .env（如 LISTENING_PORT=6555）再 docker compose up -d，本页的跳转链接会自动跟随；卡片上的端口徽标是默认值，仅供对照。
  • 端口徽标 / 直连：卡片与表格里的 :5555 之类为默认端口，实际跳转由 nginx 按 .env 决定。
  • 练习记录：生成与保存的练习会落到宿主机的 my/ 目录（容器与本地运行共用同一份数据）。
  • 局域网访问：把根目录 .env 的 BIND_ADDR 改成 0.0.0.0，手机 / 平板即可访问本页；注意应用没有登录鉴权，仅建议在可信网络短期使用。
